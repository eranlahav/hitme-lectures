# מפות המושגים

כאן נשמרות מפות המושגים של הקורס, והוויזואלים שהסטודנטים מכינים לכל מושג. זה המקור היחיד שלהן.

אחרי כל מיזוג לגרסה הראשית, פעולה אוטומטית מעתיקה את התיקייה הזו לאתר הקורס, ושם הן מוצגות כגלריה:

```
https://eranlahav.github.io/hitme-lectures/maps/
```

## המבנה

```
maps/
  index.json            ← רשימת המפות, החדשה ראשונה
  01-git/               ← מפגש 1: 15 מושגי גיט
    00-map.webp         ← המפה כולה
    concepts.json       ← שם כל מושג ושם קובץ הוויזואל שלו
    01-git.jpg          ← ויזואל של מושג
  02-research/          ← מפגש 2: 16 מושגי מחקר משתמשים
  03-synthesis/         ← מפגש 3: מאוסף אנשים להבנת אדם, 17 מושגים
  04-persona-to-product/ ← מפגש 4: מפרסונה למוצר, 17 מושגים
```

## איך מגישים ויזואל למושג

1. ב-`concepts.json` של המפה כתוב שם הקובץ שמחכה לכל מושג, למשל `04-persona.jpg`.
2. שומרים את הוויזואל בדיוק בשם הזה, בתוך תיקיית המפה.
3. פותחים בקשת מיזוג שיש בה רק את הקובץ הזה. אם השם מופיע ב-`concepts.json`, ועוד אין קובץ בשם הזה, הבקשה נכנסת לבד תוך כמה דקות. תוך חצי שעה בערך הוויזואל מופיע באתר.
4. לפני שמתחילים, בודקים שאין כבר בקשת מיזוג פתוחה לאותו מושג. מושג תפוס, בוחרים אחר.

מי הכין כל ויזואל נשמר בהיסטוריה של המאגר, לפי מי שפתח את הבקשה. לכן לא כותבים שם בתוך הקובץ או בתוך `concepts.json`.

כללים: תמונה בלבד (jpg, png, webp), עד 2 מגה, שם קובץ באנגלית בלי רווחים. מוסיפים רק קובץ חדש. שינוי של קובץ קיים, ושל `concepts.json`, עובר דרך המרצה. הבדיקה האוטומטית במאגר אוכפת את זה.

שימו לב: האתר ציבורי, אבל לא מופיע בחיפוש. בוויזואל לא שמים פנים של אנשים או פרטים מזהים.

## מפה חדשה (למרצה)

1. פותחים תיקייה `maps/<מספר>-<נושא>/`, ומכניסים את המפה.
2. כותבים `concepts.json` באותו מבנה כמו בתיקיות הקיימות, עם שם קובץ לכל מושג.
3. מוסיפים את שם התיקייה בראש `maps/index.json`.
